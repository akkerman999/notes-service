# Описание конфликта

## Где возник
Конфликт возник в файле README.md, в разделе «Описание».

## Причина
Строка описания была изменена в двух ветках по-разному:
- в ветке main — на «Сервис заметок для личного и командного использования.»
- в ветке feature/readme-update — на «Сервис заметок с поддержкой тегов и полнотекстового поиска.»

При выполнении merge feature/readme-update в main Git не смог автоматически
объединить изменения и пометил файл README.md как конфликтный.

## Как исправлен
Конфликт разрешён вручную: маркеры <<<<<<<, =======, >>>>>>> удалены,
обе версии объединены в одну строку.

Сделан отдельный коммит: Resolve merge conflict in README description.
