# notes-service

Сервис заметок — учебный проект для отработки Git workflow.

## Описание
Сервис позволяет создавать, редактировать, удалять и искать заметки.

## Структура
- README.md — описание проекта
- project-notes.md — рабочие заметки
- api-plan.md — план API
- git-conflict.md — описание конфликта
